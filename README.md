#编程工具箱·开发者版 — 用户指南

一个基于**Python + Web构建的本地编程工具箱（即“开发者版”，面向个人使用的独立发行版）。它仅使用 Python 标准库实现，因此无需任何第三方依赖即可直接运行。

##1. 如何开始

|系统|操作|
|------|------|
双击Programming-Toolbox-Developer-Edition-2.0-.bat` |#如果运行失败，请执行 Programming-Toolbox-Developer-Edition-2.0-.sh
|运行`bash 编程工具箱-开发者版-2.0-.sh`在终端中|
|通用|运行`python server.py`在此目录下|

启动后，浏览器将自动打开`http://127.0.0.1:8687`（若未自动弹出，请手动访问）。按 Ctrl+C 可停止服务器。

##2. 五大模块

###1. 代码
-四个按钮：“新建 Python / 打开 Python / 新建 C++ / 打开 C++”。文件保存在`codes/`目录下。
-**✨ AI 生成代码：在工具栏中点击“AI 生成代码”，描述您的需求，系统将调用您本地配置的开源 LLM（Ollama）生成代码，并自动将其保存为文件且在编辑器中打开。首次使用时，请从“下载”模块安装 Ollama，然后运行`ollama pull qwen2.5-coder以下载代码模型。
- **调试按钮**：当代码运行失败时，控制台输出旁边会显示一个“调试错误”按钮。点击该按钮即可跳转至调试模块，错误信息已自动加载，从而开始分析。
-首次点击“运行”（或进入该模块）时，若未检测到任何环境，将弹出一个**“设置您的 Python / 设置您的 C++”**窗口。点击“下载”即可跳转至“下载”模块。
-编辑器支持行号、Tab 缩进、`Ctrl+S`保存以及`Ctrl+Enter`运行；输出控制台位于底部。
-C++ 会自动执行 g++ 编译与运行步骤；编译错误将原样显示。

###2. 扩展
-搜索框按包名在 PyPI 上进行查询（例如 requests、numpy、pygame）。
-安装**默认使用清华大学镜像** (`https://pypi.tuna.tsinghua.edu.cn/simple`），在中国访问速度很快。
- **找不到您需要的扩展吗？**请在下方输入完整的 pip 命令进行安装，例如：`pip install pandas`.
-右侧面板会实时列出您已安装的第三方软件包。

###3. 下载
- **解释器/编译器**：Python 官方安装程序、MinGW-w64（适用于 Windows 的 g++）、MSYS2 以及清华大学镜像。
- **开源人工智能**：Ollama、LM Studio、Hugging Face、ModelScope、Open WebUI、Chatbox——点击卡片即可访问官方网站并下载。

###4. 调试
-粘贴一段 Python 异常堆栈信息或 C++ 编译/运行时错误，然后点击“开始分析”。
-内置20余条常见错误规则（如ModuleNotFoundError、IndentationError、未定义引用、段错误等），可为您提供**可能的原因、建议的修复方案以及错误发生的位置**.
-该页面还介绍了通用的调试方法论“七步法”：复现→隔离→假设→监测→验证→修复→回归。

###5. 学习（开发者版内置13门课程）
-9门基础课程：Python基础 / 控制流 / 函数与模块 / 数据结构，C++基础 / 流程与函数、算法入门、调试方法论、面向对象编程与设计模式。
-每门课程均包含详细讲解、一键可复制的示例代码以及练习任务；点击“开始编写代码”即可将示例直接导入代码模块。
- **开发者版专属高级课程（4门）**：Flask Web 开发入门、Git 版本控制、pytest 单元测试、项目工程与打包。

##3. 开发者版说明
-本应用为**独立的开发者版**,与标准版分开，仅供个人使用。
-默认端口**8687**；可与标准版（8686）并行运行。

##4. 常见问题解答

-**端口已被占用：请将`PORT = 8687`修改为其他端口，位置在server.py文件的顶部。
- **右上角显示“未配置”**：未检测到 python/g++。请从“下载”模块中安装，并重启工具箱。
- **代码文件位于何处**：全部位于本目录下的`codes/`文件夹中；您可以用任意编辑器打开它们。
